# Cyber Detective — IEEE CS JUST

A small browser-based cybersecurity booth game.

## Run locally
Open `index.html` in a modern browser. No installation is required.

## Publish
Upload all files in this folder to a GitHub repository, then import that repository into Vercel. The project is static; no build command or output directory is needed.

The original IEEE CS JUST logo is included as `ieee-cs-just-logo.png`.
